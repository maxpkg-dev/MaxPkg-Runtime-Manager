About MaxPkg

Runtime

MaxPkg is a package ecosystem for Autodesk 3ds Max. It connects developers, the maxpkg.dev catalog, and the Runtime inside 3ds Max into one distribution workflow.

Users can discover, install, run, update, and remove scripts in one place. Developers build and publish versioned tools with MaxPkg Packager—eliminating scattered installers, duplicate toolbar buttons, and inconsistent script versions across artists, workstations, and studios.

Uninstall MaxPkg

Remove MaxPkg Runtime, Manager, toolbar, startup entry, settings, and local Runtime files from this 3ds Max installation.

Your scenes are safe. Uninstalling MaxPkg does not modify your .max scene files. You can install MaxPkg again at any time.
  1. Save your current work.
  2. Click Uninstall MaxPkg and confirm the action.
  3. The Manager will close and a result window will appear when removal is finished.
